# 音频资源管理系统使用指南

本系统提供了完整的音频资源上传、管理和使用功能，特别适用于白噪音功能的音频文件管理。

## 功能概述

- **云函数**: 提供音频文件上传、获取、更新和删除的功能
- **前端页面**: 提供用户友好的界面来管理音频资源
- **白噪音集成**: 白噪音功能已更新为从云存储加载音频文件

## 已创建的云函数

1. **uploadAudioFiles**
   - 功能: 将音频文件上传到云存储并保存资源信息
   - 主要参数: `fileID`, `fileName`, `soundType`

2. **getAudioResources**
   - 功能: 管理和获取音频资源链接
   - 支持操作: `getList`, `getById`, `update`, `delete`

## 如何使用音频上传页面

1. 在小程序中导航到 **音频资源管理** 页面
2. 点击 **选择MP3文件** 按钮，从本地选择一个MP3格式的音频文件
3. 选择对应的 **声音类型**（rain、forest、waves、fireplace、wind、night）
4. 点击 **上传音频** 按钮，将音频文件上传到云存储
5. 上传成功后，音频资源将显示在已上传列表中

## 如何在白噪音功能中使用

1. 确保已上传对应的音频资源
2. 打开白噪音功能页面
3. 选择已上传音频对应的声音类型
4. 点击播放按钮，系统将自动从云存储加载并播放音频

## 支持的声音类型和文件名

| 声音类型 | 文件名 | 描述 |
|---------|--------|------|
| rain | rain.mp3 | 雨声 |
| forest | forest.mp3 | 森林声 |
| ocean | waves.mp3 | 海浪声 |
| night | night.mp3 | 夜晚环境声 |
| fireplace | fireplace.mp3 | 壁炉声 |
| meditation | meditation.mp3 | 冥想音乐 |

## 注意事项

1. 音频文件必须为MP3格式
2. 单个音频文件大小建议不超过1MB，以保证加载速度
3. 上传成功后，音频文件将存储在云存储的 `audio/` 目录下
4. 所有上传的音频资源信息将保存在数据库的 `audio_resources` 集合中
5. 如果云存储中没有找到对应音频，系统将自动切换到模拟播放模式

## 常见问题排查

1. **上传失败**: 检查网络连接或文件格式是否正确
2. **播放失败**: 确认对应类型的音频资源已上传到云存储
3. **加载缓慢**: 考虑压缩音频文件大小或使用更高质量的网络连接
